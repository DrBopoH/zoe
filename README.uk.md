# Ζωή

> Особистий фінансовий застосунок: збирає виписки банків, брокера й біржі в єдину картину капіталу.
> *Ζωή (zoe) — personal finance app: bank statements + broker + exchange → one capital chart, history and a persons/aliases graph. Runs locally, single user.*

**Статус:** білд 2 (`v1.2`, макро- та ринкові дані) закрито як стейбл `v1.s2.113+143`, далі білд 3 — полірування інтерфейсу та доробка QoL, конструкторських і довідкових фіч. Білд 1 (`v1.b1`, бета) — збір даних із банків, брокера та Binance — заморожено. Версії ведуться за схемою `R.sB.C+T.hash`, див. [docs/WORKFLOW.uk.md](docs/WORKFLOW.uk.md) і [CHANGELOG.uk.md](CHANGELOG.uk.md).

## Що вміє

- **Джерела даних:** Monobank (API), Raiffeisen (API та CSV), PrivatBank (PDF-виписка), NovaPay (CSV), брокерський звіт ICU (PDF, облігації ОВДП), виписка Binance (CSV) плюс публічні хвилинні ціни Binance. Ключ Binance не потрібен.
- **Капітал у динаміці:** свічковий графік по всіх рахунках (таймфрейми 1m…1W), історія операцій із бейджами видів; перекази між власними рахунками не вважаються ні доходом, ні витратою.
- **Особи та аліаси:** хто стоїть за іменем контрагента, які в нього рахунки й картки; зв'язки редагуються вручну й переживають скидання кешу.
- **Ринок і макро (білд 2):** облігації ОВДП (реєстр і аукціони НБУ) та US Treasury з коефіцієнтом для довгого накопичення; ставки, інфляція й курси НБУ; макро США (ФРС, крива Treasury, реальні ставки, ціни, праця, активність, ліквідність, кредит, скорекард); картки країн і єврозони (22 записи реєстру); сировина, світові акції, акції компаній США (SEC), крипто та крипто-контур, купівельна спроможність; сторінка «Источники» зі здоров'ям кожного джерела. Усе з публічних API, ключі не потрібні.
- **Єдиний формат джерел `.zoe`:** розібрані дані лежать на диску, кеш-базу можна стерти й відновити однією кнопкою; макро-ряди й дані акцій лежать там само, у групі «Экономика».

Усе працює локально: бекенд слухає лише `127.0.0.1` і перевіряє заголовок Host, а особисті дані нікуди не йдуть, окрім запитів до самих банків. Ринкові дані застосунок сам бере з публічних джерел без ключів (НБУ, Мінфін, FiscalData, FRED, ЄЦБ, Євростат, BIS, Світовий банк, Yahoo, SEC, Nasdaq, Binance та інші; повний перелік — у `backend/pkg/market`).

## Швидкий старт

Потрібні: Go (версія в `backend/go.mod`), [bun](https://bun.sh), `pdftotext` з poppler (для PDF Привату та звітів ICU).

```bash
# бекенд, порт 8080
cd backend && go run .

# фронтенд, http://localhost:5173
cd frontend && bun install && bun run dev
```

Токени банків не обов'язкові: виписки можна завантажувати файлами (Управление → Кэш → Выписки). Для синхронізації по API створи `backend/.env`:

```env
MONO_TOKENS=токен1,токен2     # або MONO_TOKEN=один_токен
RAIF_TOKENS=токен             # або RAIF_TOKEN=один_токен
```

### Налаштування середовища (бекенд)

| Змінна | За замовчуванням | Призначення |
|---|---|---|
| `MONO_TOKENS` / `MONO_TOKEN` | — | токени Monobank (список через кому або один) |
| `RAIF_TOKENS` / `RAIF_TOKEN` | — | токени Raiffeisen |
| `PORT` | `8080` | порт API |
| `HOST` | `127.0.0.1` | адреса; для доступу з іншого пристрою `0.0.0.0`, і тоді ім'я хоста фронту має бути в `ALLOWED_ORIGINS`, інакше бекенд відповідає 403 «Host not allowed» |
| `ALLOWED_ORIGINS` | `http://localhost:5173`, `http://127.0.0.1:5173` | список Origin фронту через кому |
| `CACHE_DB_PATH` | `cache.db` | одноразовий кеш виписок |
| `CORE_DB_PATH` | `core.db` | постійні дані: особи, аліаси, зв'язки |
| `MARKET_EVERY` | `1h` | як часто бекенд сам знімає знімки крипто-контуру (P2P-ціна, комісії мереж, домінація); `30m`, `2h` тощо, `0` вимикає |
| `P2P_MIN_DEAL_UAH` | `1000` | мінімальна сума угоди, ₴, щоб оголошення P2P вважалося робочим (менші ціну USDT не задають) |
| `ECONOMIC_SOURCES_DIR` | `$XDG_DATA_HOME/economic/sources`, інакше `~/.local/share/economic/sources` | тека файлів-джерел `.zoe` |

Фронтенд: `VITE_API_BASE` (за замовчуванням `http://127.0.0.1:8080/api`).

## Структура репозиторію

```
backend/    Go + SQLite (модуль economic): API, парсери виписок, сховище
frontend/   Vue 3 + Tailwind v4 + Vite (bun): Головна та «Архив» у бічному меню (Смета, Рынок, Учёт)
docs/       документація: USER.md, ARCHITECTURE.md, WORKFLOW.md
clc.sh      помічник для git і патчів (див. docs/WORKFLOW.uk.md)
.github/    CI: тести, збірка, перевірки гігієни
```

## Тести

```bash
cd backend && go test ./...
cd frontend && bun run test      # node --test tests/*.test.mjs і vitest (компоненти)
cd frontend && bun run build
```

Ті самі перевірки (плюс `gofmt`, `golangci-lint` і гігієна: немає баз, ключів, архівів і номерів карток) ганяє CI на кожен PR і на push у `dev`, `build`, `main`.

## Приватність

У репозиторії немає баз, ключів, виписок і реальних даних: тестові виписки та фікстури анонімні. `cache.db`, `core.db`, `.env` і `.zoe`-файли залишаються в тебе на машині.
